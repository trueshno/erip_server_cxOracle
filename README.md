# erip_server_cxOracleCaddy
Системы, вычисляющие стоимость услуг связи для каждого клиента и хранящие информацию обо всех тарифах и прочих стоимостных характеристиках, которые используются телекоммуникационными операторами для выставления счетов абонентам и взаиморасчетов с другими поставщиками услуг, носят название биллинговых; цикл выполняемых ими операций именуется биллингом.

### Config
eripadmin@srverip:~$ cat /etc/caddy/Caddyfile
:80 {
        reverse_proxy 127.0.0.1:8000

        header {
                Content-Type "text/xml; charset=windows-1251"
        }

        log {
                output file /var/log/caddy/erip_access.log
                format json
                level INFO
        }
}

### Rules
Сообщения передаются по протоколу HTTP методом POST на сервер производителя услуг.
Содержимое сообщения передается в параметре с именем XML. Для передачи параметра
используется multipart/form-data, поскольку позволяет передать содержимое параметра 
XML как есть.<br>

Признаком успешно доставленного сообщения является код "200" HTTP-ответа. <br>

При формировании сообщений должны использоваться символы в кодировке CP1251. <br>

Содержимое ответа о результатах обработки сообщения располагается в теле HTTP
ответа.<br>

Время ответа на запрос не должно превышать 15 секунд. При наличии большого 
количества одновременных запросов указанное время ожидания ответа может быть временно 
сокращено в целях недопущения накопления лавинообразной очереди ожидания ответов на 
запросы.<br>

На любом этапе к серверу ПУ (поставщик услуг) могут приходить повторные запросы, на которые
ПУ обязан отвечать тем же сообщением, которое было выслано ранее.<br>
